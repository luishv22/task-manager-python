# 📝 Gestor de Tareas en Python

Aplicación de consola para gestionar tareas con fecha límite opcional.

## Funcionalidades

- Agregar tareas
- Asignar fecha límite
- Listar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Guardado automático en archivo JSON

## Tecnologías usadas

- Python
- JSON (para guardar datos)

## Como usar 

1. Clona el repositorio:

```bash
git clone https://github.com/luishv22/task-manager-python.git
```

2. Entra a la carpeta del proyecto:

```bash
cd task-manager-python
```

3. Ejecuta el programa:

```bash
python main.py
```

## Ejemplo de uso

1. ❎ Estudiar Python (Límite:01/05/2026)
2. ✅ Comprar pan

## Estructura del proyecto
- main.py → Interfaz de usuario (menú)
- tareas.py → Lógica del programa
- tareas.json → Archivo donde se guardan las tareas
